## 🚀 How to Deploy on GitHub Pages

### Step 1 — Create a GitHub Repository
1. Go to [github.com](https://github.com) and sign in (or create a free account)
2. Click the **+** button → **New repository**
3. Name it: `mahaveer-group` (or any name you prefer)
4. Set it to **Public**
5. Click **Create repository**

### Step 2 — Upload All Files
1. Click **uploading an existing file** on the new repo page
2. **Drag and drop the entire `mahaveer-group` folder contents** (all files and the `assets` folder)
3. Make sure the structure matches exactly as shown above
4. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to your repository → **Settings** tab
2. Scroll down to **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Choose **Branch: main** and **/ (root)**
5. Click **Save**
6. Wait 1–2 minutes, then your site will be live at:
   `https://YOUR-USERNAME.github.io/mahaveer-group/`

## 🖼️ How to Replace Images (No Code Needed)

All images are in `assets/images/`. To replace any image:

1. Rename your new photo to **exactly** the same filename:
   - `logo.jpg` → company logo
   - `building.jpg` → real estate / hero background
   - `gym.jpg` → fitness section
   - `restaurant.jpg` → restaurant section
2. Go to `assets/images/` in your GitHub repository
3. Click the existing file → click the **pencil/edit** icon → **Delete file**, then upload your new one with the same name
   **OR** simply drag and drop the new file — GitHub will ask if you want to replace it

No need to edit any HTML or CSS. The website picks up the new image automatically.
